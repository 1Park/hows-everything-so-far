# Common contracts

Controller와 모델 서비스가 공유하는 가벼운 코드만 둔다.

- 장면·객체·bbox·요청·고객 확인·상태 이벤트·오류 schema
- 환경 파일 선택과 환경변수 우선순위를 처리하는 설정 로더
- 여러 서비스에 실제로 필요한 작은 공통 유틸리티

모델 가중치·학습 코드·GPIO·제품 정책·서버 진입점은 각 담당 폴더에 둔다. 공통 schema를 가져오기 위해 ML 학습 의존성을 설치해야 하는 구조는 피한다. bbox 좌표 규약·ID 수명·버전도 schema와 함께 기록한다. 아직 코드 구현 전이다.
